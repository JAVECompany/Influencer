# 인플루언서 권한

| 화면 | 동작 |
| --- | --- |
| 입점 | Instagram 프로필 링크 또는 표시 이름·핸들·이메일·소개를 제출한다. 검토 상태와 반려 사유를 확인하고 재신청할 수 있다. |
| 스튜디오 | 승인 후 자신의 월 구독료·소개를 수정하고 게시글·스토리·라이브 미리보기를 등록·삭제한다. |
| 상품 | 개별 사진·영상용 데모 상품과 공개 확률이 표시되는 데모 룰렛을 등록한다. |
| 채팅 | 활성 구독자의 메시지에 응답한다. |
| 수익 | 자신의 구독과 코인 소비 내역을 확인한다. 실제 정산은 수취 주체와 공제 정책 확정 후 연동한다. |
| 프로필 | 자신의 이미지·닉네임·비밀번호·알림과 가상 정산수단 표시를 관리한다. |

라이브는 편성 및 미리보기 흐름이며 영상 송출에는 스트리밍 인프라가 필요하다. 룰렛 누적 소비액에 따른 자격, 저등급·꽝 제한 구간, 최고 상품 확정가는 정책 검토 항목이다.
