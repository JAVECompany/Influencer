# 인플루언서 권한

| 화면 | 동작 |
| --- | --- |
| 입점 | Instagram 프로필 링크 또는 표시 이름·핸들·이메일·소개를 제출한다. 검토 상태와 반려 사유를 확인하고 재신청할 수 있다. |
| 스튜디오 | 승인 후 자신의 월 구독료·소개를 수정하고 게시글·스토리·라이브 미리보기를 등록·삭제한다. 자신의 스토리 조회 고객과 라이브 미리보기 참여자를 확인할 수 있다. 콘텐츠마다 고객 한 명을 한 번씩 집계하며 관리자 검수는 제외한다. |
| 상품 | 개별 사진·영상 상품을 등록하고 자신의 썸네일과 원본을 열람한다. 룰렛 상품명과 당첨 확률을 설정하며, 확률에 따라 원판 칸 크기가 정해진다. 1등 확정가는 선택 사항이다. 미리보기에서는 고객과 같은 원판을 체험할 수 있다. |
| 채팅 | 현재 내 콘텐츠를 구독 중인 고객만 대화 목록에 표시되며, 해당 고객에게 메시지를 보낼 수 있다. |
| 수익 | 자신의 구독과 코인 소비 내역을 확인한다. 실제 정산은 수취 주체와 공제 정책 확정 후 연동한다. |
| 프로필 | 자신의 이미지·닉네임·비밀번호·알림과 가상 정산수단 표시를 관리한다. |

라이브는 편성 및 미리보기 흐름이며 영상 송출에는 스트리밍 인프라가 필요하다. 룰렛 누적 소비액에 따른 자격과 제한 구간은 정책 검토 항목이다.
