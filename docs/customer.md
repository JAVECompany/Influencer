# 고객 권한

| 화면 | 동작 |
| --- | --- |
| 홈 | 활성 구독 중인 크리에이터의 스토리·라이브 미리보기와 게시글을 열람한다. 게시글 좋아요와 신고를 할 수 있다. |
| 검색 | 승인된 프로필을 드래그하거나 방향키로 돌려 탐색한다. 구독 중인 프로필은 처음에 중앙에 모이고, 구체를 돌리면 다른 카드와 함께 움직인다. 카드에 전체 구독자 수를 표시하며 닉네임·핸들로 검색할 수 있다. |
| 크리에이터 상세 | 미구독 상태에서는 월 가격과 구독 버튼을 본다. 구독 후 개별 상품 및 룰렛에 코인을 쓸 수 있다. 미구매 상품은 흐린 썸네일로 보이고 구매 후 썸네일과 원본이 열린다. |
| 룰렛 | 상품명, 상품별 당첨 확률, 회당 가격을 확인한다. 원판은 추첨된 상품 칸에 멈춘다. 크리에이터가 1등 확정가를 설정하면 별도로 확인해 구매할 수 있다. |
| 채팅 | 구독 중인 크리에이터에게 메시지를 보낸다. |
| 스토어 | 코인 묶음으로 모의 충전하고 구매·사용 내역을 확인한다. |
| 프로필 | 프로필 이미지·닉네임·비밀번호·전체 알림을 변경하고 가상 결제수단과 구독을 관리한다. |

정식 가입은 약관 동의 후 PASS에서 만 19세 이상 여부를 확인하고 ID·비밀번호·고유 닉네임을 받는 흐름이다. 데모 가입은 모의 성인 확인만 사용한다. 다른 탭으로 전환하면 게시물·스토리·라이브 미리보기와 구매 콘텐츠가 가려진다.
