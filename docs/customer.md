# 고객 권한

| 화면 | 동작 |
| --- | --- |
| 홈 | 활성 구독 중인 크리에이터의 스토리·라이브 미리보기와 게시글을 열람한다. 게시글 좋아요와 신고를 할 수 있다. |
| 검색 | 승인된 프로필을 사진·닉네임 중심으로 탐색한다. 원형 카드는 구독자 수에 따라 크기가 다르다. 닉네임·핸들로 검색한다. |
| 크리에이터 상세 | 미구독 상태에서는 월 가격과 구독 버튼을 본다. 구독 후 게시글·스토리·라이브를 열고 개별 상품 및 룰렛에 코인을 쓸 수 있다. |
| 채팅 | 구독 중인 크리에이터에게 메시지를 보낸다. |
| 스토어 | 코인 묶음으로 모의 충전하고 구매·사용 내역을 확인한다. |
| 프로필 | 프로필 이미지·닉네임·비밀번호·전체 알림을 변경하고 가상 결제수단과 구독을 관리한다. |

정식 가입은 약관 동의 후 PASS에서 만 19세 이상 여부를 확인하고 ID·비밀번호·고유 닉네임을 받는 흐름이다. 데모 가입은 모의 성인 확인만 사용한다. 게시물·스토리·라이브 미리보기에는 이용자 ID 워터마크와 탭 전환 시 가림을 적용한다.
