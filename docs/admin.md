# 관리자 권한

| 화면 | 동작 |
| --- | --- |
| 운영 개요 | 입점 신청 수, 운영 계정, 구독·코인 거래 현황을 본다. |
| 입점 심사 | 직접 입력 정보 또는 Instagram 링크를 검토하고 승인·반려한다. 반려 사유는 신청자에게 표시된다. |
| 계정 관리 | 고객·인플루언서의 이용 상태를 변경한다. 승인 프로필이라도 이용 정지되면 고객 검색과 구독 기능에서 제외된다. |
| 콘텐츠 관리 | 게시글·스토리·라이브와 고객 신고를 확인하고 공개 상태를 변경한다. |
| 거래·정산 | 구독권과 코인 충전·사용 내역을 전체 조회한다. 수납·송금은 운영 단계에서 연동한다. |
| 프로필 | 관리자 계정 설정을 변경한다. |

정식 서비스에서는 역할, 콘텐츠 소유권, 구독 상태를 서버에서 검증하고 운영 행위를 감사 로그에 기록한다.
