# 관리자 권한

| 화면 | 동작 |
| --- | --- |
| 운영 개요 | 심사 대기 건수, 공개 크리에이터, 신고 콘텐츠 현황을 본다. |
| 심사 요청 목록 | 직접 입력 정보 또는 Instagram 링크를 검토하고 승인·반려한다. 반려 사유는 신청자에게 표시된다. |
| 홈 · 크리에이터 상세 | 고객 홈과 같은 형식으로 전체 콘텐츠를 검수한다. 상세에서 판매 종료 상품을 포함한 등록 상품의 썸네일과 원본을 열 수 있다. 관리자 열람은 스토리 조회수, 라이브 참여자 수, 고객 명단, 구매, 구독자 수, 정산에 반영하지 않는다. |
| 계정 관리 | 등록 계정과 승인된 크리에이터 프로필을 함께 조회한다. 로그인 계정이 없는 승인 크리에이터도 이용 정지·복구할 수 있으며, 정지된 프로필은 고객 검색과 구독 기능에서 제외된다. |
| 콘텐츠 관리 | 게시글·스토리·라이브와 고객 신고를 확인하고 공개 상태를 변경한다. |
| 거래·정산 | 조회 기간별 크리에이터 코인 사용량·환산액과 월별 구독권 매출을 본다. 코인 환산 단가, 플랫폼 수수료율, 기간별 정산 코인 수를 설정해 지급 예정액을 계산한다. |
| 프로필 | 관리자 계정 설정을 변경한다. |

정식 서비스에서는 역할, 콘텐츠 소유권, 구독 상태를 서버에서 검증하고 운영 행위를 감사 로그에 기록한다.
