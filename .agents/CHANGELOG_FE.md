# 프론트엔드 변경 이력

최근 변경을 위에 두고 날짜와 함께 화면, 동작, 구조에 생긴 변화를 기록한다. 배포 이력은 실제 반영이 확인된 경우에만 기록한다.

## 2026-11-10

- Zustand 스토어 파일을 `auth/auth.ts`, `wallet/wallet.ts`처럼 도메인별 짧은 이름으로 정리하고 상태 갱신에 Immer를 적용했다. 도메인 판정, 입력 검증, 구매 계산과 레코드 생성을 공통 유틸로 분리했다. 데모와 테마의 저장 키 및 데이터 형식을 유지했다. TypeScript 타입 검사와 이전 경로 참조를 확인했다.

- 디지털·실물 상품을 관리자 승인 후 판매하도록 변경했다. 기존 직접 등록 상품은 검수 대기로 전환하고, 판매가 중지되지 않은 기존 디지털 구매 이력은 보존한다. 실물 상품 주문에 예시 배송지 입력과 한 개 재고 차감, 판매자 발송 처리, 구매자 상태 조회를 추가했다. TypeScript 타입 검사를 통과했다.

- 모든 역할의 프로필에 테마 선택을 추가했다. 기본으로 시스템 설정을 따르며 Zustand에서 브라우저별 설정을 저장한다. 다크·라이트·밤결·리퀴드 글래스·페리윙클·피치·모카 팔레트를 파일별로 분리하고 공통 색상 토큰을 적용했다. 반복 제목과 설명을 줄이고 알림 설정을 스위치로 표시했다. TypeScript 타입 검사와 팔레트의 공통 토큰 선언을 확인했다.

- Zustand 액션을 인증·계정·크리에이터·콘텐츠·구독·지갑·상품·룰렛·정산·채팅 slice로 분리했다. 공통 컴포넌트·훅·유틸을 기능별 폴더로 정리했다.
- 크리에이터 탐색에서 구독 프로필을 처음 위치의 중앙에 배치하고 회전 시 함께 움직이도록 했다. 카드를 촘촘히 배치하고 전체 구독자 수를 표시하며 상하 드래그 방향을 수정했다.
- 크리에이터 채팅에서 본인의 활성 구독자만 대화할 수 있다는 규칙을 명시하고, 대화 목록과 메시지 전송에 같은 구독 조건을 적용한다.
- 운영 계정 관리에 로그인 계정이 없는 승인 크리에이터를 포함하고 이용 정지·복구를 지원한다.
- 룰렛 원판 칸과 추첨에 같은 확률을 사용하고, 추첨된 칸까지 연속으로 감속한다. 원판과 결과에 상품명을 표시하고 데모 기본 상품을 5개로 구성했다.
- 구독 콘텐츠와 개별 구매 콘텐츠의 일반 열람 화면에서 계정 ID·열람 시각 워터마크를 제거했다.
- React 소스를 앱 조립, 페이지별 기능, 공용 코드로 재배치했다. 화면과 내부 컴포넌트를 분리하고 React 컴포넌트 하나당 파일 하나로 구성했다.
- 공통 UI 프리미티브와 콘텐츠·상품·룰렛·장부 컴포넌트를 공용 영역으로 옮겼다. 페이지 전용 폼과 다이얼로그, 훅과 계산 모듈은 각 페이지에 배치했다.
- 역할별 화면 연결과 브라우저 데모 저장 키 및 데이터 구조를 유지했다.
- 개발 지침과 프론트엔드·백엔드 규칙 및 변경 이력을 `.agents/`에 추가했다.
- 테스트, 린트, 빌드는 사용자가 별도로 요청할 때만 수행하도록 개발 지침을 명시했다.
- 저장소에 Prettier 설정을 추가하고 리팩터링한 TypeScript 소스에 같은 포맷을 적용했다.
