# 백엔드 규칙

## 현재 구현

- 밤결은 Vite로 빌드하는 정적 웹 데모다. 현재 별도의 API 서버, 데이터베이스 또는 외부 결제·송금 연동이 없다.
- 브라우저 저장소에 있는 인증, 구독, 코인, 룰렛, 정산, 채팅 동작은 로컬 데모 구현으로 분류한다. 해당 코드는 프론트엔드 규칙과 변경 이력에서 관리한다.
- 실제 비밀번호, 인증 수단, 계좌번호, 결제 키, 비공개 원본은 데모 데이터와 배포 파일에서 제외한다.

## 서버가 도입되는 경우

- 인증, 역할과 리소스 소유권, 구독 상태, 구매 권한은 서버가 요청마다 판정한다. API의 요청·응답, 오류, 권한과 저장 모델은 구현과 함께 문서화한다.
- 코인 차감, 구독 및 구매 원장 기록, 룰렛 결과 저장 등 함께 성공해야 하는 상태 변경은 하나의 트랜잭션으로 처리한다. 중복 요청, 재시도, 동시 처리에서 중복 차감과 지급을 방지한다.
- 금액과 코인은 정수 단위로 관리하고 수수료 단위, 반올림, 정산 기간의 한국시간 경계를 계약에 명시한다. 룰렛의 표시 비중과 실제 추첨 확률을 구분한다.
- 실제 구독 콘텐츠와 구매 원본의 접근 권한은 서버 또는 저장소의 접근 제어로 적용한다. 화면 워터마크와 가림은 프론트엔드 표시 정책으로 유지한다.
- 백엔드가 도입되면 실행·검증 방법과 API 및 DB 변경 사항을 [백엔드 변경 이력](CHANGELOG_BE.md)에 기록한다.
